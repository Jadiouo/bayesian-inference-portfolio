# 00 · 環境熱身測試

動任何專案前，先跑這個確認環境通了（對應計劃書 §0.2）。

```bash
conda activate bayes
python 00_warmup/warmup_pymc.py
```

**場景**：診斷檢測 20 人受檢、3 人陽性，估計真陽性率 θ。

**通關標準**
1. `r_hat < 1.01`（收斂）
2. 後驗均值 ≈ 0.18（眾數 ≈ 0.15）
3. 95% HDI ≈ `[0.04, 0.33]` —— 注意它有多寬：**20 個樣本能告訴你的事情很有限**

跑完會在本資料夾產生 `warmup_posterior.png`：一座偏左的山，峰值約 0.15。
這張圖就是計劃書主題三「可信區間」——你可以合法地說「真陽性率有 95% 機率落在這個區間」。
