# 4-1 · Laplace 近似

> [!abstract] 主題四是課程的轉折點
> 前三個主題在建立**理論**,從這裡開始講**怎麼把理論落地**。
>
> Laplace 近似是最簡單的近似方法,它的思路很粗暴:**「不知道真後驗長什麼樣?那就硬塞一個高斯進去,在 MAP 附近做泰勒展開。」**

> [!question] 本卡核心問題
> - 後驗很複雜時,有什麼**最便宜的近似策略**?
> - 為什麼需要 **Hessian 矩陣**?它在幹嘛?
> - 這個近似什麼時候**夠好**、什麼時候**會出大事**?

---

## ① 直覺鋪墊:從山頂推測整座山

你**站在迷霧中的一座山頂**,看不到全貌,但想畫出這座山。

你能做兩件事:
- **找到山頂位置**(MAP)—— 你站的地方
- **感覺山頂的「斜率變化」**(Hessian)—— 這裡有多陡、多平、多彎

光從這兩件事,你能畫出整座山嗎?**完全不行**。但你可以畫一個合理的猜測:

> 🔑 **「這座山在山頂附近,大概長得像一座我熟悉的小山(高斯)。山頂的彎度告訴我這座小山要多寬多窄。」**

### 兩個必須記住的假設

1. **後驗的最高峰夠重要,可以代表整座山**(後驗單峰)
2. **山頂附近的形狀,可以用二次曲線合理近似**

當這兩個假設成立,Laplace 快、簡單、夠好。當其中一個失敗,**Laplace 會自信地給你錯誤答案** —— 這是它最危險的地方。

---

## ② 正式定義

$$\boxed{\;p(\theta\mid D) \approx \mathcal{N}\big(\hat\theta_{\text{MAP}},\;H^{-1}\big)\;}$$

其中 $H$ 是「負對數後驗」在 MAP 點的 Hessian:

$$H = -\nabla^2_\theta\log p(\theta\mid D)\Big|_{\theta=\hat\theta_{\text{MAP}}}$$

### 🔊 念出來

> 「在 D 之下 θ 的機率,**約等於**,以 MAP 為中心、以 Hessian 反矩陣為協方差的高斯」

### 🖼️ 畫面

```
真實後驗(可能複雜):        Laplace 近似(強制高斯):
       ___                          _∩_
     _/   \_                       /   \
    /       \___                  /     \
   /            \_               /       \
  ─────●────────────  θ        ──●──────────  θ
       ↑                         ↑
       MAP                       MAP(位置相同)
                                 寬度由 H 決定
```

---

## ③ 為什麼是這個式子?二階泰勒展開

在 MAP 點對 $\log p(\theta\mid D)$ 做泰勒展開:

$$\log p(\theta\mid D) \approx \underbrace{\log p(\hat\theta\mid D)}_{\text{常數}} + \underbrace{\nabla\log p(\hat\theta\mid D)^\top(\theta-\hat\theta)}_{=\,0\;\text{(MAP 是極值點)}} - \tfrac12(\theta-\hat\theta)^\top H(\theta-\hat\theta)$$

一階項在 MAP 點等於 0,所以:

$$p(\theta\mid D) \approx C\exp\Big(-\tfrac12(\theta-\hat\theta)^\top H(\theta-\hat\theta)\Big)$$

**這個形狀就是高斯!** 對照 $\mathcal{N}(\hat\theta,\Sigma)\propto\exp(-\tfrac12(\theta-\hat\theta)^\top\Sigma^{-1}(\theta-\hat\theta))$:

$$\Sigma = H^{-1}$$

> 🔑 **Laplace 近似就是這麼來的:在 MAP 附近做二階泰勒,自動長出一個高斯。**

### 🔧 Hessian 的直覺:曲率 = 確定性

| 山頂形狀 | Hessian | $H^{-1}$ | 語意 |
|---|---|---|---|
| **很彎、尖** | 大 | 小 | 高斯近似窄 → **我很確定** |
| **很平、寬** | 小 | 大 | 高斯近似寬 → **我不太確定** |

> 🔑 **口訣:「曲率 = 確定性」。**
> $\Sigma = H^{-1}$ 就是「確定性的倒數 = 不確定性 = 協方差」。
>
> 這連回 [[2-2_共軛先驗與指數族]] 的「精確度加權平均」—— 精確度 $\tau$ 就是 Hessian 在 1 維下的版本,協方差就是 $1/\tau$。

---

## ④ 為什麼「兩個量」剛好夠?

> [!important] 這是本卡最容易被忽略的深層問題
> **一個高斯分佈,只需要兩個參數就能完全描述**:
> - **均值** —— 山頂的位置 → 用 **MAP**
> - **變異數** —— 山的寬度 → 用 **$H^{-1}$**
>
> **少一個不行**(只知道山頂在哪,不知道山多寬,畫不出來)
> **多一個不需要**(高斯本來就只有兩個自由度 —— 它沒有偏度、沒有額外峰度)

多維時:
- **均值向量** $\hat\theta$($d$ 個數字)
- **協方差矩陣** $H^{-1}$($d(d+1)/2$ 個獨立數字)

**剛好對應 MAP 和 Hessian,沒有任何浪費。**

> 🔑 **這不是工程取捨,是「用高斯近似」這個假設的數學必然。**
>
> 如果選其他分佈(Student-t、混合高斯),你就需要更多的量。**Laplace 選了高斯,代價就是你只能描述「均值和變異數」這兩個層級的形狀資訊。**

**這連回 [[2-3_最大熵先驗]]**:「只測前兩階矩 → 高斯是最誠實的選擇」。Laplace 近似就是這個原則的具體實現 —— **在 MAP 點測前兩階矩,然後用最大熵答案補完整座山**。

---

## ⑤ 為什麼這個近似這麼有用?

### 用途 1:完全繞過 $p(D)$

Laplace 只需要兩個東西:

1. **MAP 點**(用最佳化算,不需要 $p(D)$)
2. **MAP 點的 Hessian**(二階導數,也不需要 $p(D)$)

> 🎯 **這就是為什麼 Laplace 這麼便宜** —— 只要算「峰值在哪、峰值多彎」。

### 用途 2:給點估計一個信心區間

$$95\%\text{ 可信區間}: \hat\theta \pm 1.96\sqrt{H^{-1}}$$

**不用花更多計算成本,就從點估計升級成有不確定性的估計。**

### 用途 3:它連到 KF

- KF 的 $\hat x_{t\mid t}$ 是 MAP(也是後驗均值,高斯下相等)
- KF 的 $P_{t\mid t}$ 是 Hessian 的反矩陣

> 🔑 **KF 是 Laplace 近似的「免費版本」** —— 在線性高斯下,Laplace 近似**剛好等於精確後驗**,所以你不用做近似。離開線性高斯,Laplace 才變成主動需要計算的東西。

## ⑥ 三種失敗模式

### 🚨 失敗 1:雙峰後驗

```
真實後驗:  ▲    ▲          Laplace(瞄準左峰):
          / \  / \                    ▲
         /   \/   \                  / \
       ─●────────●────            ──●──────
        MAP1   MAP2                 MAP1
```

**Laplace 只看到一個峰,完全忽略另一個峰的存在。**

> 🚨 **這是最危險的失敗模式** —— 不是「答案不準」,而是「**答案看起來很有信心,但其實藏著一個你沒看見的另一個世界**」。
>
> 給出的「95% 可信區間」**只覆蓋一個峰**,完全錯失另一個峰。
>
> **如果你懷疑後驗可能多峰,絕對不能用 Laplace。**

### 🚨 失敗 2:嚴重偏斜後驗

```
真實後驗(右偏):              Laplace(強制對稱):
       ▲                              _∩_
      /│\___                         /   \
     / │   \___                     /     \
   ─●───┼──────────              ──●─────────
```

**問題**:Hessian 是**局部資訊**,只看 MAP 點本身。偏斜後驗的「左邊彎度」和「右邊彎度」不一樣,但 Laplace 只能給一個彎度 → 平均了兩邊。

結果:**真實的長尾被砍掉,真實沒有的左尾被「鏡像」生成出來。**

**緩解**:**變數變換**。對 $\theta > 0$ 的量先做 $\phi = \log\theta$,在 log 空間做 Laplace(那邊常常對稱得多),再變回來。

### 🚨 失敗 3:支撐受限

$\theta\in[0,\infty)$ 的後驗(電阻、方差、機率⋯)。高斯近似**會把機率質量分到 $\theta<0$ 的不可能區域**。

## ⑦ 電機工程類比:EKF 就是 Laplace 的動態版

> 🔑 **EKF 是 Laplace 近似在「動態系統」場景下的實現。**

| | EKF | Laplace 近似 |
|---|---|---|
| **在哪做近似** | 當前估計點 $\hat x_{t\mid t-1}$ | MAP 點 $\hat\theta$ |
| **用什麼近似** | **一階**泰勒(線性化動態) | **二階**泰勒(二次化對數後驗) |
| **結果** | 假裝系統是線性高斯 | 假裝後驗是高斯 |
| **共同假設** | 「在那一點附近,真的東西夠平滑/夠對稱」 | 同上 |

### EKF 什麼時候出事?

**和 Laplace 的失敗模式精準對應**:

| EKF 的失敗 | Laplace 的失敗 |
|---|---|
| **真實噪音不是高斯**(IMU 尖峰) | 真實後驗不是高斯(重尾) |
| **真實狀態分佈多峰** | 後驗雙峰 |
| 線性化點附近的曲率不能代表整體 | MAP 點附近的曲率不能代表整體 |

> 🔑 **核心連結**:
> **EKF 失敗的時候,Laplace 近似在對應的靜態問題上也會失敗。**
> **解決 EKF 問題要用 Particle Filter,解決 Laplace 問題要用 MCMC —— 兩者都是「放棄高斯假設」的方向。**

### 其他 EE 類比

- **LMS / RLS 自適應濾波器**:在當前估計點對誤差函數做二階泰勒展開,沿梯度更新 —— Laplace 思路的訊號處理版本
- **電路的量測誤差傳遞分析**:算工作點的偏導數(雅可比/Hessian),用線性近似估計輸出方差 —— **正是 Laplace 的精神**
- **Fisher 資訊矩陣**:在 MLE 真實值附近等於 Hessian 的期望 —— 這就是為什麼 Fisher 矩陣常被用來估計神經網路權重的不確定性

## 🎓 費曼檢驗

### 問題 1
Laplace 只用了兩個量(MAP 和 Hessian)。為什麼這兩個量足夠?多了不需要、少了不行?

> [!success]- 參考答案
> **因為高斯分佈只有兩個自由度**:均值和變異數。
> - 均值 ← MAP(高斯山的山頂就是均值)
> - 變異數 ← $H^{-1}$(高斯山的彎度就是 $1/\sigma^2$)
>
> **少一個**:只知山頂在哪、不知山多寬 → 畫不出整座山
> **多一個**:高斯**沒有**偏度、沒有額外峰度可以描述 —— 你多告訴它也用不上
>
> 🔑 **這不是工程取捨,是「用高斯近似」這個假設的數學必然。**

### 問題 2
三種後驗形狀,Laplace 會不會出問題?
- A:單峰對稱高斯
- B:兩個幾乎等高的峰
- C:極度偏斜,長尾在右

> [!success]- 參考答案
> - **A → 合理**。這正是 Laplace 的最佳條件。
> - **B → 會出大事**(不只是「勉強可用」)。Laplace 會找到其中一個峰,**完全失去另一個峰的存在訊息**。給出的 95% 區間只覆蓋一個峰。**這比「答案不準」更危險 —— 它看起來很有信心,但藏著一個你沒看見的世界。**
> - **C → 會出大事**。Hessian 是**局部**資訊,而偏斜後驗左右彎度不同。Laplace 強制對稱 → 真實長尾被砍掉,不存在的左尾被鏡像生成。**緩解:先做 log 變換再做 Laplace。**

### 問題 3
為什麼 EKF 是 Laplace 近似的特例?它什麼時候會出事?

> [!success]- 參考答案
> **EKF 是 Laplace 在動態系統的實現**:在當前估計點做泰勒展開,假裝結果是高斯,然後傳到下一步。
>
> **出事的時機和 Laplace 精準對應**:
> - 真實分佈不是高斯(IMU 鋸齒、多峰、重尾)→ 兩者都崩
> - 局部曲率不能代表整體 → 兩者都崩
>
> ⚠️ **關鍵提醒**:EKF 處理的是**非線性**,不是**非高斯**。它只是把彎的路面壓平,噪音模型仍然是高斯。**薄尾的問題一個字都沒動到。**
>
> **解法**:Particle Filter(動態)/ MCMC(靜態)—— **都是放棄高斯假設的方向**。
