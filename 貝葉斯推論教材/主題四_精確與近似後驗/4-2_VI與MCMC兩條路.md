# 4-2 · VI 與 MCMC:兩條路

> [!question] 本卡核心問題
> Laplace 強制用高斯,失敗模式很多。還有什麼策略?
>
> - 為什麼 VI 和 MCMC 是「**兩條路**」,而不是同一條路的不同版本?
> - 工程上什麼時候選哪條?**VAE 為什麼選 VI?Stan 為什麼選 MCMC?**

---

## ① 直覺鋪墊:兩種策略還原一座山

回到那座迷霧中的山。

### 🎨 策略 1:用「可調的家族」逼近(VI)

你帶了一本**形狀目錄冊** —— 裡面有一千種你會畫的山形,每種都有可調參數。

**工作**:從目錄冊裡找出和真實山「最像」的那一種。

- **快** —— 只要在目錄冊裡搜尋,不用真的爬山
- **但有限制** —— 如果真的山形目錄冊裡沒有,你只能找一個最近似的,**永遠有差距**
- **數學上**:差距用 KL 散度量度;你在做的是**優化問題**

> 🔑 **VI = 把「找後驗」轉換成「在分佈家族裡優化參數」的問題。**

### 🎨 策略 2:用「採樣」探索(MCMC)

你不帶目錄冊。你派一個**機器人**在山上走來走去,每走幾步記錄一下高度。

走久了,機器人留下的**足跡密度**會反映整座山的形狀。

- **慢** —— 機器人要走很久
- **但精準** —— 走夠久會得到真實山的精準採樣,**沒有家族假設限制**
- **數學上**:你在做的是**採樣問題**

> 🔑 **MCMC = 不假設後驗形狀,直接「採樣」逼近整座山。**

### 一句話區分

| 學派 | 核心動詞 | 比喻 |
|---|---|---|
| **VI** | **找** | 在目錄冊裡**翻**到最像的山 |
| **MCMC** | **走** | 派機器人**走**遍真實的山 |

> 💡 **你以後看到任何貝葉斯近似法,都可以問:「這是優化還是採樣?」** —— 一刀切下去就能歸類。

---

## ② VI 的數學

定義一個**可調的近似分佈家族** $q_\phi(\theta)$。例如 **Mean-Field 高斯家族**:

$$q_\phi(\theta) = \prod_{i=1}^d\mathcal{N}(\theta_i;\mu_i,\sigma_i^2)$$

**優化目標**:

$$\phi^* = \arg\min_\phi\text{KL}\big(q_\phi(\theta)\,\|\,p(\theta\mid D)\big)$$

> 🔊 **念**:「讓 q 和真實後驗的 KL 散度最小的那個 φ」
> 🖼️ **畫面**:在「形狀目錄冊」裡找一座最接近真實後驗的山

> [!warning] 🚨 但這裡有個悖論
> 這個式子裡有 $p(\theta\mid D)$ —— **而它就是我們算不出來的東西!**
>
> 這像是「用魔法找魔法書」。**解決方法就是 [[5-1_ELBO的第一原理推導]] 的 ELBO。**
> 現在只要知道「VI 透過 ELBO 把目標變得可算」就好。

---

## ③ MCMC 的數學

設計一個**馬可夫鏈**:從 $\theta^{(0)}$ 開始,按規則跳到 $\theta^{(1)}, \theta^{(2)},\ldots$

**設計目標**:讓這個鏈的**長期穩態分佈** = 真實後驗。

跳了很久之後,$\{\theta^{(t)}\}$ 的足跡密度**就是真實後驗**。

### 🪄 最神奇的地方:不需要 $p(D)$

Metropolis-Hastings 的接受機率:

$$\alpha = \min\left(1,\;\frac{p(\theta'\mid D)}{p(\theta^{(t)}\mid D)}\right) = \min\left(1,\;\frac{p(D\mid\theta')p(\theta')}{p(D\mid\theta^{(t)})p(\theta^{(t)})}\right)$$

**$p(D)$ 在分子和分母上下消掉了!**

> 🔑 **MCMC 不需要算 $p(D)$,因為它從來不用後驗的「絕對值」,只用「比值」。** → [[4-3_MCMC的核心直覺]]

---

## ④ 工程比較

| 面向 | VI | MCMC |
|---|---|---|
| **基本策略** | 從家族中**優化** | 從後驗**採樣** |
| **計算速度** | 快 | 慢(每步採樣 + 等收斂) |
| **可規模化** | ✅ 神經網路規模可行 | ❌ 大模型很難跑 |
| **無偏性** | ❌ **系統性偏差**(取決於家族選擇) | ✅ 漸近無偏 |
| **失敗模式** | **偏差不會自己被發現** | 收斂慢,但**有診斷工具** |
| **典型應用** | VAE、貝葉斯深度學習 | Stan、PyMC、貝葉斯統計建模 |
| **核心瓶頸** | 家族表達力 | 採樣效率 |

## ⑤ VI 的兩個失敗模式(必須知道)

### 🚨 失敗 1:Mode-Seeking(找峰)

KL 散度**不是對稱的**。VI 用的是 $\text{KL}(q\,\|\,p)$,這個方向有個專有性質:

> 🔑 **當真實後驗是雙峰,VI 用單峰高斯近似時,它會選擇「擠進其中一個峰」,而不是「展開覆蓋兩個峰」。**

```
真實後驗:  ▲    ▲          VI 近似(Mean-Field):
          / \  / \                ▲
         /   \/   \              / \  ← 擠進左峰,完全忽略右峰
        /    /\    \            /   \
      ──────────────          ─────────
```

**結果:VI 給你一個「對某個峰非常確定」的近似,但漏掉另一個峰。**

### 🚨 失敗 2:Mean-Field 抹掉相關性

假設真實後驗是**強相關的橢圓**:

```
真實後驗:              VI(Mean-Field)近似:

   ╭──────╮               ┌─────┐
  ╱        ╲              │  •  │    ← 比真實後驗窄很多
 ╱  真實    ╲             │     │       不能反映 θ₁ 和 θ₂ 的相關性
  ╲ 後驗   ╱              └─────┘
   ╲──────╯
```

Mean-Field 假設 $q(\theta_1,\theta_2) = q_1(\theta_1)q_2(\theta_2)$ —— **強行把兩個變數視為獨立**。

**災難在哪?** VI 給的近似**比真實後驗窄很多** —— 它的「95% 可信區間」會**嚴重低估真實的不確定性**。

> 🔑 **核心教訓:VI 的失敗不是「答案不準」,而是「答案看起來很準,但藏著系統性偏差」。**
>
> **這比 MCMC 的「採樣慢」可怕得多 —— 慢你會發現,但偏差你不會。**

### 救援方法

| 方法 | 做什麼 |
|---|---|
| **Full-rank VI** | 不假設獨立,允許 $q_\phi$ 是完整協方差的高斯 |
| **Normalizing Flows** | 用神經網路定義非常彈性的 $q_\phi$,可逼近任意分佈 |

## ⑥ MCMC 的工程痛點

| 痛點 | 說明 |
|---|---|
| **收斂判斷** | 採樣 1000 次夠嗎?10000 次?需要 trace plot、ESS、多鏈 $\hat R$ |
| **自相關高** | 連續樣本高度相關,10000 步可能只等效於幾百個獨立樣本 |
| **高維時極慢** | 提議落在「合理」區域的機率指數級下降 |

**這些都是工程經驗,沒有萬無一失的判斷** —— 也是 MCMC 不適合即時系統的原因。

## ⑦ 為什麼現代 ML 這樣選?

### 📌 VAE → 為什麼選 VI?

- **大規模**:數據幾百萬筆,模型幾百萬到幾億參數
- **即時**:每個 mini-batch 都要更新,每秒幾百次
- **近似可接受**:生成模型對「精確後驗」的要求沒那麼高

→ **MCMC 跑不動,VI 才能規模化。** VAE 的 ELBO loss 就是 VI 的優化目標。

### 📌 Stan / PyMC → 為什麼選 MCMC?

- **小到中型**:幾十到幾千個參數
- **離線分析**:可以跑幾分鐘到幾小時
- **準確度至上**:科學研究、藥效分析 —— **不能容忍系統性偏差**

→ **計算成本可負擔,MCMC 的無偏性很值錢。**

### 📌 工業界的中間選擇

- **MC Dropout** → 極廉價的 VI(→ [[6-2_MC_Dropout]])
- **Deep Ensemble** → 貝葉斯模型平均的廉價版
- **Stochastic Gradient MCMC(SGLD)** → 用隨機梯度的 MCMC,可跑大模型

## 🎓 費曼檢驗

### 問題 1
為什麼 VI 是「優化問題」,MCMC 是「採樣問題」?

> [!success]- 參考答案
> - **VI 在「找」**:從一個分佈家族裡,優化參數,選出最像真實後驗的成員。
> - **MCMC 在「走」**:不假設任何形狀,派機器人採樣,用足跡密度逼近後驗。
>
> **一句話**:VI 在優化(選家族成員),MCMC 在採樣(生成樣本)。

### 問題 2
三個案子選 VI 還是 MCMC?
- A:訓練 1 億參數的圖像生成模型,每秒幾百次更新
- B:醫學研究,50 位病人的療效,不能容忍偏差
- C:即時自駕車姿態估計

> [!success]- 參考答案
> - **A → VI**。參數量太大、更新太頻繁,MCMC 跑不動。
> - **B → MCMC**。有時間、要嚴謹,MCMC 漸近無偏的性質很值錢。
> - **C → 優化派**,但**動態系統有專門的工具**,不會用「純 VI」:
>   - 線性、高斯 → **EKF / UKF**(Laplace 流派)
>   - 有非高斯狀況 → **Particle Filter**(採樣派,但要付計算代價)
>   - 中間 → 變分 KF / 深度卡爾曼

### 問題 3
Particle Filter 屬於哪一條路?為什麼它能處理 EKF 處理不了的場景?代價是什麼?

> [!success]- 參考答案
> **屬於「採樣派」** —— 嚴格說是 **SMC(Sequential Monte Carlo)**,不是嚴格的 MCMC:
> - **MCMC**:在「靜態的後驗」上跑馬可夫鏈
> - **SMC/PF**:在「**動態演化的後驗**」上做粒子採樣 + 重要性權重 + 重採樣
>
> **為什麼能處理 EKF 處理不了的?** ⚠️ **不只是「能處理非線性」** ——
> **關鍵是它不假設任何分佈形狀**,所以非線性、非高斯、多峰、重尾**都能處理**。
> (EKF 處理非線性但強制高斯,所以 IMU 鋸齒會崩)
>
> **代價**:每時刻要追蹤幾百到幾千個粒子並重採樣,計算成本遠高於 KF。這正是採樣派的標準特性 —— **精度高,但計算貴**。
