## 🔍 名詞索引

### 貝葉斯基本框架

| 名詞 | 一句話定義 | 卡片 |
|---|---|---|
| **先驗** $p(\theta)$ | 看到資料前的信念,是一個**分佈** | [[1-1_四個項的認識論意義]] |
| **似然** $p(D\mid\theta)$ | 「假設真值是 θ,看到 D 的機率」;在推論裡是 **θ 的函數** | [[1-1_四個項的認識論意義]] |
| **後驗** $p(\theta\mid D)$ | 看完資料後的信念,貝葉斯推論的**最終產品** | [[1-1_四個項的認識論意義]] |
| **邊際似然 / Evidence** $p(D)$ | 歸一化常數;**在模型選擇裡是模型分數** | [[1-3_邊際似然的困境]] · [[7-3_貝葉斯模型選擇]] |
| **序貫更新** | 今日後驗 = 明日先驗,是**恆等式**不是近似 | [[1-2_序貫更新與Kalman Filter]] |
| **Cox 定理** | 滿足理性公理的推理系統,必然是機率論 | [[1-1_四個項的認識論意義]] |
| **Dutch Book** | 不用貝葉斯更新 = 信念有內在矛盾,可被變現 | [[1-1_四個項的認識論意義]] |
| **維度詛咒** | 高維時積分/採樣/搜尋全部指數級變難 | [[1-3_邊際似然的困境]] · [[7-2_貝葉斯最優化]] |

### 先驗設計

| 名詞 | 一句話定義 | 卡片 |
|---|---|---|
| **參數化不變性** | 真正的「無知」不該因為換變數而改變 | [[2-1_無資訊先驗與Jeffreys]] |
| **Jeffreys Prior** | $p_J(\theta)\propto\sqrt{\det I(\theta)}$,參數化不變的無資訊先驗 | [[2-1_無資訊先驗與Jeffreys]] |
| **弱資訊先驗** | 高維時的實務選擇,如 $\mathcal{N}(0,\sigma_0^2I)$ | [[2-1_無資訊先驗與Jeffreys]] |
| **Improper prior** | 不可歸一化的先驗;**不能用於貝氏因子** | [[2-1_無資訊先驗與Jeffreys]] · [[7-3_貝葉斯模型選擇]] |
| **共軛先驗** | 先驗和後驗住在同一分佈家族 | [[2-2_共軛先驗與指數族]] |
| **擬計數** | 「我在看真資料前虛擬看過幾筆」;**只有共軛指數族有這個解讀** | [[2-2_共軛先驗與指數族]] |
| **指數族** | $p(x\mid\theta)=h(x)\exp(\eta^\top T(x)-A(\theta))$;統計學的自然座標系 | [[2-2_共軛先驗與指數族]] |
| **充分統計量** $T(x)$ | 資料中唯一影響推論的摘要 | [[2-2_共軛先驗與指數族]] |
| **最大熵原理** | 在約束下選熵最大的分佈 = 只編碼已知,其餘不假設 | [[2-3_最大熵先驗]] |
| **精確度加權平均** | $\mu_N=\frac{\tau_0\mu_0+N\tau_y\bar y}{\tau_0+N\tau_y}$;KF 的數學核心 | [[2-2_共軛先驗與指數族]] |

## 🧭 三條貫穿全課的主線

### 主線 1 · 「怎麼繞過 $p(D)$」

```
1-3 發現問題:p(D) 算不出來
      ↓
  ┌───┴───┬────────┬─────────┐
 MAP   Laplace    VI       MCMC
不歸一化  假裝高斯  變下界   用比值消掉
 (1-3)   (4-1)   (5-1)     (4-3)
                    ↓
              MC Dropout / Ensemble
                  (6-2)
      ↓
7-3 反轉:p(D) 其實是模型的分數
```

### 主線 2 · 「不確定性從負擔變成資源」

```
1-1 後驗是一個分佈,不是一個點
      ↓
3-2 用整座山預測比用山頭準
      ↓
6-3 不確定性有兩種,各自需要不同行動
      ↓
7-1 Epistemic 高 → 棄權是最優行動
      ↓
7-2 σ(x) 大的地方 → 最值得去做實驗
```

### 主線 3 · 「探索 vs 利用」

```
4-3 MCMC:只上山會卡住,要允許下山
      ↓
7-2 BO:UCB 的 κ 就是這個旋鈕
      ↓
(課外)RL、MCTS、Active Learning
```

## 🚨 全課易錯點清單

複習時可以拿這張表自我檢查:

| 易錯點 | 正確版本 | 卡片 |
|---|---|---|
| 混淆先驗/似然/數據/後驗的**類型** | 先驗後驗是**分佈**,數據是**數字**,似然是**量測裝置的可信度模型** | [[1-1_四個項的認識論意義]] |
| 以為「無資訊 = 不影響後驗」 | **沒有任何先驗能不影響後驗**;問題是「影響得公不公平」 | [[2-1_無資訊先驗與Jeffreys]] |
| 高維時選均勻先驗 | **均勻在高維更糟**(無法歸一化、極度病態);用弱資訊高斯 | [[2-1_無資訊先驗與Jeffreys]] |
| 以為「都是高斯」就共軛 | 還需要**線性**;神經網路 $f_\theta$ 非線性 → 不共軛 | [[2-2_共軛先驗與指數族]] |
| 最大熵的因果方向搞反 | 是「**約束 → 優化 → 形狀**」,不是「看到高斯所以選高斯」 | [[2-3_最大熵先驗]] |
| 以為 MAP 是貝葉斯的正統結論 | MAP 只是 **0-1 損失**下的最優;回歸問題該用後驗均值 | [[3-1_點估計與損失函數]] |
| 以為 EKF 解決了 IMU 鋸齒 | EKF 治**非線性**,不治**非高斯**;要 Robust KF 或 PF | [[4-1_Laplace近似]] · [[A2_三個神問]] |
| 以為 BNN 最終要的是 $w$ 的後驗 | **$w$ 被積掉了**;要的是 $y^*$ 的預測分佈 | [[6-1_貝葉斯神經網路]] |
| 把重參數化當成「解決後驗難算」 | 重參數化解決的是**梯度穿過採樣**,不是後驗難算 | [[5-3_重參數化技巧]] |
| 以為 KF 的 Aleatoric($R$)會隨時間變 | **$R$ 固定不變**;會下降到穩態的是 Epistemic($HPH^T$) | [[6-3_兩種不確定性]] |
| 決策門檻公式分子放錯 | $p^*=\frac{C_{FP}}{C_{FP}+C_{FN}}$;**漏報可怕 → 門檻要低** | [[7-1_貝葉斯決策框架]] |
| 以為貝葉斯永遠偏好簡單模型 | 是「**解釋力相當時**偏好簡單」 | [[7-3_貝葉斯模型選擇]] |
| 用 improper prior 算貝氏因子 | **絕對禁止** —— 分數會變成任意數字 | [[7-3_貝葉斯模型選擇]] |
