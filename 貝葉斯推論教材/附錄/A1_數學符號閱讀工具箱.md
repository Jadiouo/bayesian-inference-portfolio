# 附錄 A1 · 數學符號閱讀工具箱

> [!important] 為什麼這個附錄排在最前面
> 學貝葉斯最常見的卡點,**不是概念聽不懂,而是「文字看得懂,但式子看不懂」**。
>
> 症狀是:你能理解「後驗均值是山的重心」這句話,但看到 $\mathbb{E}[\theta\mid D] = \int \theta\,p(\theta\mid D)\,d\theta$ 時腦中一片空白。
>
> **這不是智力問題,是缺一個翻譯層。** 這個附錄就是那個翻譯層。

---

## 工具 1 · 讀音表

> [!tip] 核心心法
> **數學家看式子時,腦中會默默念出聲。**
> 如果你看式子時腦中是「靜音」的,就像看樂譜不哼旋律 —— 當然抓不到感覺。
>
> **練法**:照著下表把式子**念出聲**,念到順,念到不用想。

| 符號 | 怎麼讀(中文) |
|---|---|
| $p(\theta)$ | 「θ 的機率」 |
| $p(\theta \mid D)$ | 「**在 D 之下**,θ 的機率」 |
| $p(D \mid \theta)$ | 「**在 θ 之下**,D 的機率」 |
| $\propto$ | 「正比於」 |
| $\int f(\theta)\,d\theta$ | 「**對 θ**,把 f **積起來**」 |
| $\mathbb{E}[\theta]$ | 「θ 的期望值」/「θ 的平均」/「θ 的重心」 |
| $\mathbb{E}_q[\,\cdot\,]$ | 「**在 q 之下**,某某的期望值」 |
| $\arg\max_\theta f(\theta)$ | 「**讓 f 最大的那個 θ**」 |
| $\max_\theta f(\theta)$ | 「f 的**最大值**」 |
| $\text{KL}(q\,\|\,p)$ | 「q 和 p 的 KL 散度」 |
| $\nabla_\theta f$ | 「f 對 θ 的梯度」 |

### 一個關鍵區分:$\max$ 和 $\arg\max$

這兩個超容易混,但意義完全不同:

- $\max_\theta\,p(\theta\mid D)$ = **山頂的高度**(一個機率值)
- $\arg\max_\theta\,p(\theta\mid D)$ = **山頂的位置**(一個 θ 值)

> 🔑 **MAP 在乎的是「山頂在哪個 θ 上」,不在乎山有多高。**

### 練習:把這條式子念出來

$$p(\theta\mid D) = \frac{p(D\mid\theta)\,p(\theta)}{p(D)}$$

> 「**在 D 之下 θ 的機率**,等於,**在 θ 之下 D 的機率**,乘以,**θ 的機率**,除以,**D 的機率**」

念一次、兩次、三次。**念到順為止**。念順之後,它就從一坨符號變成一句你會講的話。

## 工具 2 · 畫面字典

> [!tip] 核心心法
> 每條式子都要配一張畫面。**看到符號 → 腦中浮現形狀**,這才叫看懂。

### 基本畫面

| 概念 | 畫面 |
|---|---|
| $p(\theta)$ | **一座山**(橫軸是 θ 的所有可能值,高度是「我相信這個 θ 的程度」) |
| $p(\theta\mid D)$ | **看完 D 之後,變窄變高的山** |
| $p(D\mid\theta)$(在貝葉斯式子裡) | **也是 θ 的山** —— 描述哪個 θ 比較能解釋已經量到的 D |
| 兩個分佈相乘 | **兩座山逐點相乘** —— 重疊的地方被加強 |
| $\int p(\theta)\,d\theta = 1$ | **山下的總面積 = 1** |
| $\int \theta\,p(\theta)\,d\theta$ | **山的重心位置** |
| 後驗預測分佈 | **無數座小山按權重合成一座新山** |

### 畫面 1:先驗 → 後驗

```
     p(θ)                    p(θ|D)
   (先驗山)                 (後驗山)
      __                       │
    _/  \_                    ╱│╲
   /      \                  ╱ │ ╲       ← 看完 D 之後
  /        \_               ╱  │  ╲        變窄變高
 ────────────             ───────────
      θ                        θ
 (寬、平、不確定)          (窄、尖、確定)
```

### 畫面 2:兩座山相乘

```
  先驗山:       __
              _/  \_
             /      \
           __         \__
          ────────────────  θ

  似然山:          __
                  /  \
                _/    \_
               /        \____
            ────────────────  θ

  乘起來:          ▲
                  / \         ← 兩座山「重疊的地方」被加強
                 / | \
              __/  |  \__
            ────────────────  θ
                  ↑
            後驗山(更窄、更尖)
```

> 🔑 **後驗山 = 先驗山 × 似然山 的重疊區域。**
> 兩座山都同意的地方,後驗山很高;只有一座山支持的地方,後驗山變低。

### 畫面 3:MAP 和後驗均值的差別

```
       ▲             ← 山頂(MAP)= 山最高的位置
      /│\
     / │ \
    /  │  \
   /  ▼    \         ← 重心(後驗均值)
  /   │     \           = 整座山「平均」一下,中心在哪
 /    │      \________
─────────────────────── θ
```

- **對稱單峰山**:山頂和重心**重合**(高斯後驗就是這種,所以 KF 裡 MAP = 後驗均值)
- **偏斜山**:重心會被**長尾拉走**,但山頂不動 → 兩者分裂
- **雙峰山**:山頂在某一個峰上,重心**卡在兩峰中間的山谷裡** → 分裂最嚴重

## 工具 3 · 積分三步驟

> [!tip] 核心心法
> 看到任何積分,**不要慌,問三個問題就好**。

### 三步驟

1. **被積項裡有哪些變數?**(寫在條件位置的不算,例如 $p(\theta\mid D)$ 裡的 $D$)
2. **$d$ 旁邊要積掉誰?**
3. **剩下什麼?**
   - **全積掉** → 一個**數字**(面積、重心、機率值)
   - **剩一個變數** → 一條**曲線**(一座山)
   - **剩兩個變數** → 一個**面**

### 一條鐵則

> [!warning] 貝葉斯課裡的所有 $\int\cdots d\theta$,都是「對 θ 全空間的**定積分**」
>
> **θ 一定會被徹底吃掉,不會剩下來當變數。**
>
> 這和微積分課的**不定積分**($\int x\,dx = x^2/2$,結果還是 x 的函數)完全不同。
> 積分結果裡的變數,**只會是那些沒被 $d\cdot$ 標記的變數**。

### 四個範例

| 式子 | 變數 | 積掉 | 剩下 | 結果 |
|---|---|---|---|---|
| $\int p(\theta\mid D)\,d\theta$ | $\theta$ | $\theta$ | 無 | **數字**(= 1,面積) |
| $\int \theta\,p(\theta\mid D)\,d\theta$ | $\theta$ | $\theta$ | 無 | **數字**(重心位置) |
| $\int p(y\mid x,\theta)\,p(\theta\mid D)\,d\theta$ | $y, \theta$ | $\theta$ | $y$ | **一座 y 的山** |
| $\int L(\theta,a)\,p(\theta\mid D)\,d\theta$ | $\theta, a$ | $\theta$ | $a$ | **一條 a 的曲線** |

### 一個容易搞混的點:面積 vs 重心

前兩個範例都是「全積掉 → 一個數字」,但意義完全不同:

| 式子 | 被積項的物理意義 | 結果 |
|---|---|---|
| $\int p(\theta)\,d\theta$ | 純粹是**密度** | **總面積**(總質量)= 1 |
| $\int \theta\,p(\theta)\,d\theta$ | **位置 × 密度** | **重心位置** |
| $\int \theta^2\,p(\theta)\,d\theta$ | **位置² × 密度** | **二階矩**(用來算變異數) |

> 🔑 **這就是高中物理算質量中心的公式**:$x_{\text{重心}} = \int x\,\rho(x)\,dx$。
> 在貝葉斯裡,「位置」是 $\theta$,「密度」是 $p(\theta\mid D)$。**完全一模一樣。**

## 工具 4 · 分辨「變數」和「條件」

這是最容易出錯、但最好學的一件事。

$$p(y^*\mid x^*, \theta)$$

- **豎線左邊**($y^*$)= **變數** —— 這是分佈在描述的東西
- **豎線右邊**($x^*, \theta$)= **條件** —— 這些是已經給定的、固定的

> 🔑 **積分時,只有「變數」會被積掉。條件位置的東西一直都是固定的。**

### 一個經典陷阱:$p(D\mid\theta)$ 到底是誰的函數?

**看你在問什麼:**

- **如果 $\theta$ 固定、$D$ 在變**:它在問「假設真實值是 $\theta$,我會看到什麼樣的 $D$?」→ **這是 D 的分佈**
- **如果 $D$ 已經量到了、$\theta$ 在變**:它在問「這個 $D$ 已經發生,哪個 $\theta$ 比較能解釋它?」→ **這叫「似然函數」,是 θ 的函數**

**在貝葉斯定理裡,$D$ 已經量到了,$\theta$ 在變** —— 所以 $p(D\mid\theta)$ 是**θ 的函數**,即使寫法看起來像「D 的機率」。

## 練習題(附解答)

### 練習 1
$$\hat\theta_{\text{MAP}} = \arg\max_\theta\, p(\theta\mid D)$$
念出來,並說出畫面。

> [!success]- 解答
> **念**:「θ 的 MAP,等於,**讓** 在 D 之下 θ 的機率 **最大的那個 θ**」
> **畫面**:後驗山的**山頂位置**(θ 軸上的一個點,不是山頂的高度)

### 練習 2
$$\text{ELBO}(q) = \mathbb{E}_q[\log p(D\mid\theta)] - \text{KL}(q(\theta)\,\|\,p(\theta))$$
念出來,並說出兩個項各自在做什麼。

> [!success]- 解答
> **念**:「ELBO,等於,q 的期望值,在 θ 之下 D 的機率的 log,**減去**,q 和先驗 p 的 KL 散度」
> **第一項(重建項)**:q 採樣的模型,能不能解釋數據? → MLE 的精神
> **第二項(正則項)**:q 有沒有離先驗太遠? → L2 正則化的精神
> **一句話**:ELBO = 擬合 − 正則

### 練習 3
$$p(y^*\mid D) = \int p(y^*\mid\theta)\,p(\theta\mid D)\,d\theta$$
用三步驟工具分析,並說出畫面。

> [!success]- 解答
> **變數**:$y^*, \theta$ · **積掉**:$\theta$ · **剩下**:$y^*$ · **結果**:一座 $y^*$ 的山
> **畫面**:每個可能的 $\theta$ 都給出一座「預測小山」,把它們按後驗的可信度**加權平均**,合成一座新的大山。
> 這座新山通常**比任何單一小山都寬** —— 因為它把「我對 θ 也不確定」這件事疊進去了。
