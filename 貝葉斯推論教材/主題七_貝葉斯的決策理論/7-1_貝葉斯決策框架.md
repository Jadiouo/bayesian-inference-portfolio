# 7-1 · 貝葉斯決策框架

> [!abstract] 前六個主題都在學「怎麼得到後驗」
> 但後驗**不是目的** —— 它是中間產品。最終你要**做一件事**:剎車還是繼續?開刀還是觀察?
>
> **這一站回答:怎麼從一座山,走到一個行動?**

---

## ① 直覺鋪墊:醫生的兩個問題不是同一個

病人做了篩檢,結果陽性。你是醫生。

### 🩺 問題 1(估計問題)

> **「這個病人得病的機率是多少?」**

用 [[1-1_四個項的認識論意義]] 的貝葉斯定理:盛行率 1%、準確率 99% → 後驗約 **50%**。

**這是關於「真相」的問題。答案是一個數字(或一座山)。**

### 🩺 問題 2(決策問題)

> **「我要不要開始治療?」**

**這是完全不同的問題。答案不是數字,是一個行動。**

而且要回答它,你必須知道**額外的東西**:

| 你必須知道 | 為什麼 |
|---|---|
| 治療的副作用有多大? | 誤治健康人的代價 |
| 不治療會怎樣? | 漏掉病人的代價 |
| 能不能先觀察一週? | 還有第三種選項 |

> 🔑 **核心洞察**
> **後驗告訴你「世界可能是什麼樣」。**
> **損失函數告訴你「不同的錯誤,各自要付多少代價」。**
> **只有兩者合起來,才能得出行動。**

**這就是為什麼主題七存在**:前六個主題給了你後驗,但**後驗單獨無法決定行動**。

---

## ② 正式定義:決策問題的三個組件

### 🧩 組件 1:狀態空間 $\Theta$
世界可能的真實狀態 $\theta$。你不知道它,但有後驗 $p(\theta\mid D)$。

### 🧩 組件 2:行動空間 $\mathcal{A}$
你可以採取的行動 $a$。例:$\{$治療, 不治療, 再檢查$\}$

> [!important] 這是本站最重要的升級
> **[[3-1_點估計與損失函數]] 時,行動空間就是參數空間** —— 「猜一個 $\theta$ 的值」。
>
> **但真實的決策,行動空間和參數空間通常完全不同。**

### 🧩 組件 3:損失函數 $L(\theta, a)$

| | $\theta =$ 有病 | $\theta =$ 沒病 |
|---|---|---|
| $a =$ 治療 | 0(正確) | 5(副作用+成本) |
| $a =$ 不治療 | 100(可能致命) | 0(正確) |

### 🎯 貝葉斯最優決策

$$\boxed{\;a^* = \arg\min_{a\in\mathcal{A}}\underbrace{\int L(\theta,a)\,p(\theta\mid D)\,d\theta}_{\text{後驗期望損失}\;\rho(a)}\;}$$

> 🔊 **念**:「最優行動 $a^*$,等於,讓『損失乘上後驗、對 θ 積分』最小的那個 $a$」

🔍 **三步驟檢查**:變數 $\theta, a$ · 積掉 $\theta$ · 剩下 $a$ · 結果:**$a$ 的函數**(離散行動時是一張表)

### 🖼️ 畫面

```
Step 1:對每個候選行動 a,把後驗山「加權平均」它的損失

        ρ(治療)   = 0×0.5   + 5×0.5  = 2.5
        ρ(不治療) = 100×0.5 + 0×0.5  = 50.0

Step 2:選最小的 → a* = 治療 ✅
```

> 🔑 **後驗是橋樑,損失函數是目標。**
> 後驗把「不確定性」量化;損失函數把「後果」量化;期望損失把兩者相乘積分,得到一個**可以直接比較的數字**。

## ③ 這一站和主題三第一卡的差別

| | [[3-1_點估計與損失函數]] | 7-1 決策框架 |
|---|---|---|
| **行動是什麼?** | 猜一個 $\theta$ 的值 | **任何行動**(可以和 $\theta$ 完全無關) |
| **行動空間** | $\mathcal{A}=\Theta$(同一個空間) | $\mathcal{A}\neq\Theta$(通常不同) |
| **典型損失** | $(\theta-a)^2$、$\vert\theta-a\vert$、0-1 | **任意的成本表** |
| **結論** | 平方損失 → 後驗均值 | **沒有通用結論,逐案計算** |
| **例子** | 「pitch 角是幾度?」 | 「要不要啟動應急降落?」 |

> 🔑 **主題三是「估計理論」,主題七是「決策理論」。估計理論是決策理論的特例** —— 當你的行動剛好是「報告一個 θ 值」時。

### 一個具體對比

- **估計問題**:「無人機高度是多少?」→ 行動空間 = 實數線 → 平方損失 → **後驗均值**
- **決策問題**:「要不要拉升?」→ 行動空間 = $\{$拉升, 維持, 下降$\}$ → **算三個期望損失,選最小**

> 🚨 **注意:後驗均值可能是 50 公尺,但最優行動可能是「拉升」,即使 50 公尺看起來很安全** —— 因為後驗的左尾有 5% 機率低於 10 公尺,而撞地的損失是天文數字。
>
> **最優行動由「後驗的形狀 × 損失的形狀」共同決定,不是由後驗的中心決定。**

## ④ 最實用的結論:最優門檻不是 0.5

二元分類,後驗機率 $p$。損失表:

| | 有病 | 沒病 |
|---|---|---|
| **治療** | $0$ | $C_{FP}$(誤治) |
| **不治療** | $C_{FN}$(漏診) | $0$ |

### 算兩個期望損失

$$\rho(\text{治療}) = C_{FP}(1-p),\qquad \rho(\text{不治療}) = C_{FN}\,p$$

### 什麼時候該治療?

$$C_{FP}(1-p) < C_{FN}\,p \;\Longrightarrow\; \boxed{\;p > \frac{C_{FP}}{C_{FP}+C_{FN}} = p^*\;}$$

> 🔑 **最優決策門檻 $p^*$ 完全由「兩種錯誤的代價比」決定,和後驗本身無關。**

| 情境 | $C_{FP}$ | $C_{FN}$ | 門檻 $p^*$ |
|---|---|---|---|
| **兩種錯誤等價** | 1 | 1 | **0.5** ← 大家以為的預設值 |
| **漏診致命,誤治只是吃藥** | 1 | 100 | **0.0099**(1% 就該治!) |
| **誤治要開刀,漏診可再觀察** | 50 | 1 | **0.98**(要非常確定才動刀) |

### 🚨 為什麼這反直覺?

**大部分程式碼預設用 0.5**:

```python
prediction = 1 if prob > 0.5 else 0   # ← 這行藏著一個假設!
```

> 🚨 **這行程式碼等於偷偷宣告:「兩種錯誤的代價一樣」。**
>
> **在絕大多數真實應用裡,這個假設是錯的**:詐欺偵測、自駕車煞車、垃圾郵件 —— 兩種錯誤的代價都差幾個數量級。

### 🔑 一個永遠不會記錯的檢查法

> **問自己:哪一種錯誤比較可怕?**
>
> - **漏報比較可怕** → 系統應該**寧可錯殺,不可放過** → **門檻要低**
> - **誤報比較可怕** → 系統應該**寧可放過,不可錯殺** → **門檻要高**
>
> **口訣:「哪種錯誤比較可怕,門檻就往哪邊倒。」**

> [!tip] 更保險的做法:不要記公式,直接算
> 遇到這類問題,**直接算兩個期望損失比大小**:
> $$\rho(\text{告警}) = C_{FP}\times(1-p),\qquad \rho(\text{不告警}) = C_{FN}\times p$$
> **算術更簡單,而且不可能記錯分子分母的方向。**

### 回到醫院檢測的例子

後驗是 50%,不是 99%。**但如果門檻是 1%,50% 遠遠超過門檻 → 應該治療。**

> 🔑 **「後驗只有 50%」和「應該治療」完全不矛盾** —— 決策看的是「後驗 vs 門檻」,不是「後驗 vs 直覺」。

## ⑤ 棄權選項:「我不確定」的最優行動

**這一節把主題六(不確定性)和主題七(決策)接起來 —— 這是整門課最實用的接口。**

行動空間擴充:$\mathcal{A} = \{$治療, 不治療, **轉診/再檢查**$\}$

第三個行動叫**棄權(reject / abstain)**,損失是一個**固定常數** $C_{\text{reject}}$。

$$\rho(\text{治療}) = C_{FP}(1-p),\quad \rho(\text{不治療}) = C_{FN}p,\quad \rho(\text{棄權}) = C_{\text{reject}}$$

### 🖼️ 畫出來(這張圖非常美)

```
期望損失
   │
   │╲                                    ╱
   │ ╲  ρ(不治療)              ρ(治療) ╱
   │  ╲                              ╱
   │───╲────────────────────────────╱───  ρ(棄權) = C_reject
   │    ╲                          ╱
   │     ╲________________________╱
   └────┬────┬──────────────┬────┬──────  p
        0   p_low          p_high  1

     不治療  │    棄權區     │   治療
```

> 🔑 **中間出現了一個「棄權區」** —— 當後驗機率落在中間,**最優行動是「不做決定」**。

### 這解釋了三件事

**1. 為什麼「不確定就交給人類」是數學上最優的**
不是工程上的偷懶,是**貝葉斯決策理論推出來的最優行動**。

**2. 棄權區的寬度由 $C_{\text{reject}}$ 決定**

| $C_{\text{reject}}$ | 棄權區 |
|---|---|
| 很小(人工複核便宜) | **很寬** —— 稍微不確定就交給人 |
| 很大(轉診代價高) | **很窄** —— 只有極度不確定才棄權 |
| 大於所有其他損失 | **消失** —— 永遠不棄權 |

**3. 這是 [[6-3_兩種不確定性]] 的直接應用**

**Epistemic 高 = 「我沒見過這類輸入」→ 後驗預測分佈很寬 → 後驗機率靠近中間 → 落入棄權區 → 觸發人工複核。**

> 🔑 **完整的工程管線**:
>
> **BNN/MC Dropout 給你 Epistemic 不確定性 → 貝葉斯決策框架把它轉成「該不該棄權」的判斷 → 系統自動決定要不要找人類。**

## ⑥ 電機工程類比:這就是檢測理論

你 EE 學過的**檢測理論(Detection Theory)**,本質上就是貝葉斯決策理論。

### 雷達檢測問題

$H_0$:沒有目標(只有雜訊) vs $H_1$:有目標

| 錯誤 | 檢測理論的名字 | 決策理論的名字 |
|---|---|---|
| 沒目標卻報有 | **虛警(False Alarm)** | False Positive |
| 有目標卻沒報 | **漏檢(Missed Detection)** | False Negative |

### 貝葉斯檢測器

$$\frac{p(y\mid H_1)}{p(y\mid H_0)}\;\underset{H_0}{\overset{H_1}{\gtrless}}\;\frac{P(H_0)}{P(H_1)}\cdot\frac{C_{FA}-C_{00}}{C_{MD}-C_{11}}$$

左邊是**似然比**,右邊是**門檻** —— 由**先驗機率**和**代價比**共同決定。

> 🔑 **把後驗用貝葉斯定理展開,今天推的門檻公式會完全還原成這條似然比檢定。**
>
> **你在通訊/雷達學的「檢測理論」,就是貝葉斯決策理論在二元假設檢定下的特例。你早就會了,只是它當時叫另一個名字。**

### 三個熟悉的對應

| 檢測理論 | 貝葉斯決策理論 |
|---|---|
| 似然比檢定 | 後驗期望損失比較 |
| **ROC 曲線** | 掃過所有門檻,畫出兩種錯誤率的取捨 |
| **CFAR**(恆虛警率) | 固定 $P_{FA}$ 反推門檻 = **Neyman-Pearson 準則** |

### Neyman-Pearson vs 貝葉斯

| | Neyman-Pearson | 貝葉斯決策 |
|---|---|---|
| **需要先驗嗎?** | ❌ | ✅ |
| **需要代價嗎?** | ❌ | ✅ |
| **怎麼定門檻?** | 固定虛警率(例如 $10^{-6}$) | 由代價比和先驗算出 |
| **適合什麼場景?** | 代價難量化、法規規定虛警率 | 代價可量化、有可靠先驗 |

> 🔑 **這是 [[A2_三個神問]] 神問 3 的另一個實例:Neyman-Pearson 在「代價無法量化」時仍然可用,貝葉斯不行。**

## ⑦ 誠實的提醒:損失函數從哪裡來?

$$a^* = \arg\min_a\int L(\theta,a)\,p(\theta\mid D)\,d\theta$$

**這條公式假設你已經知道 $L$。**

### 🚨 現實是:$L$ 常常比後驗還難得到

- 「漏診一個癌症」的代價,用什麼單位算?
- 「自駕車撞到人」vs「急煞造成追撞」的代價比是多少?

**這些數字牽涉倫理、法律、社會共識,不是工程師能單方面決定的。**

### 工程上的三種應對

| 策略 | 做法 |
|---|---|
| **敏感度分析** | 掃過一個 $L$ 的範圍,看最優決策在哪個區間內穩定 |
| **多目標呈現** | 不給單一答案,給出 ROC 曲線讓決策者自己選門檻 |
| **反推法** | 觀察專家的實際決策,反推他們隱含的 $L$(逆強化學習的雛形) |

> 🔑 **誠實的做法是:把「後驗」和「損失假設」分開報告,讓決策者看到哪部分是數學、哪部分是價值判斷。**

## 🎓 費曼檢驗

### 問題 1
主題七的決策框架,比主題三多了什麼?用飛控的例子說明。

> [!success]- 參考答案
> **多了「行動空間」這個概念**,而且行動空間**不再等於參數空間**。同時也多了「決策的標準」(損失函數)。
>
> **飛控例子**:
> - **估計問題**:「前方有障礙物的機率是多少?」→ 行動空間是 $[0,1]$ → 答案是一個數字
> - **決策問題**:「要不要閃躲?」→ 行動空間是 $\{$閃躲, 不閃躲, 減速觀察$\}$ → 答案是一個**行動**
>
> **關鍵**:即使後驗說「50% 有障礙物」,這個數字**本身無法回答該不該閃**。你還需要知道閃躲的代價和不閃的代價。
> - 不閃的代價是閃的 200 倍 → **50% 遠超門檻,一定要閃**
> - 閃躲本身很危險(狹窄空間)→ 門檻可能是 0.9 → **50% 不該閃**
>
> **後驗給你「50%」,但 50% 不是答案,是輸入。決策理論才是把它轉成「拉桿往左」的那個東西。**

### 問題 2
無人機電池異常偵測。誤報成本 = 1(提早降落),漏報成本 = 200(炸機)。門檻是多少?$p=0.02$ 該不該告警?

> [!success]- 參考答案
> $$p^* = \frac{C_{FP}}{C_{FP}+C_{FN}} = \frac{1}{1+200} \approx \boxed{0.005}$$
>
> **門檻是 0.5%,不是 99%!**
>
> ⚠️ **檢查方向**:漏報比較可怕(200 倍)→ 系統應該**寧可錯殺不可放過** → **門檻要低**。0.005 ✅
>
> **$p = 0.02 > 0.005$ → 應該告警,立刻降落。**
>
> **用期望損失驗算**(更保險):
> $$\rho(\text{告警}) = 1\times0.98 = 0.98,\qquad \rho(\text{不告警}) = 200\times0.02 = 4.0$$
> $4.0 > 0.98$ → 告警的期望損失小得多 ✅
>
> **如果用 0.5 當門檻**:模型說 $p=0.4$「有 40% 機率電池要掛了」→ 系統不告警 → 期望損失 $200\times0.4 = 80$,而降落只要 $0.6$。**你為了省 0.6 承擔了 80 的期望損失。**

### 問題 3
設計一個完整的 IMU 決策管線,含 Epistemic / Aleatoric 和棄權選項。

> [!success]- 參考答案
> | 情況 | 診斷 | 行動 |
> |---|---|---|
> | **Epistemic 低 + Aleatoric 低** | 一切正常 | ✅ **正常運作,信任估計** |
> | **Epistemic 低 + Aleatoric 高** | 感測器很吵,但我懂這個狀況 | ⚙️ **調大 $R$,降低該感測器權重**;啟用多感測器融合 |
> | **Epistemic 高 + Aleatoric 低** | 沒見過的工況 | 🚨 **切換備援 / 保守模式**;記錄資料回去訓練 |
> | **Epistemic 高 + Aleatoric 高** | 雙重困境 | 🛑 **棄權** —— 請求人工介入 / 安全降落 |
>
> **為什麼兩者不能觸發相同行動?**
> - **Aleatoric 高 = 物理極限** → 系統再努力也無法改善 → **調整策略適應它**
> - **Epistemic 高 = 知識缺口** → 系統**不知道自己在算什麼** → **不要相信自己的輸出**
