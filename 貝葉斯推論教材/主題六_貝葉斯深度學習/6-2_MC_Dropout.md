# 6-2 · MC Dropout = 貝葉斯近似

> [!abstract] 2016 年的一個震撼結論
> Yarin Gal 證明了:**你每天在用的 Dropout,其實一直在做變分推論。**
>
> **只要測試時不關掉 Dropout,採樣多次,你就免費得到了貝葉斯不確定性估計。**

> [!question] 本卡核心問題
> - Dropout 原本是「防止 overfitting 的工程技巧」—— **它怎麼會變成貝葉斯推論**?
> - 為什麼「測試時保持 Dropout 開著」就能得到不確定性?
> - 它便宜到什麼程度?代價是什麼?

---

## ① 先複習:Dropout 原本在做什麼?

> **訓練時**,隨機把一些神經元「關掉」,防止網路過度依賴特定神經元。
> **測試時**,把所有神經元打開,輸出乘上保留率。

```
訓練時(Dropout 開):        測試時(標準做法):

  ○ → ✕ (被關掉)              ○ → ○ (全開)
  ○ → ○                       ○ → ○
  ○ → ✕ (被關掉)              ○ → ○
  ○ → ○                       ○ → ○
```

**一般的解釋**(工程直覺版):
- 防止 co-adaptation
- 像 ensemble(每次 dropout 產生一個子網路)
- 正則化效果

**這些都對,但都是「直覺」,沒有嚴謹的數學基礎。Gal 2016 給了它一個完整的貝葉斯解釋。**

---

## ② 核心洞察 1:Dropout 定義了一個 $q_\phi(w)$

Dropout 在做的事,數學上是:

$$W_{\text{dropout}} = W\cdot\text{diag}(z),\qquad z_i\sim\text{Bernoulli}(p)$$

**翻譯**:每個神經元有機率 $p$ 保留、$1-p$ 被關掉。

### 🪄 關鍵一步:這就是一個 $q_\phi(w)$!

$$w_i = \begin{cases} W_i & \text{機率 } p\;(\text{保留})\\ 0 & \text{機率 } 1-p\;(\text{關掉})\end{cases}$$

**這是一個關於權重的機率分佈** —— 參數 $\phi$ 就是 $W$ 本身(你訓練的那些權重)。

```
Bayes by Backprop 的 q_φ(w):        Dropout 的 q_φ(w):

  w_i ~ N(μ_i, σ_i²)                 w_i ~ { W_i  機率 p
                                            { 0    機率 1-p

  連續的高斯分佈                      離散的「開/關」分佈
  ▁▄█▄▁                              ▁___█  (兩個點的分佈)
```

> 🔑 **Dropout 不是「一個訓練技巧」,它定義了一個非常特殊的近似後驗 $q_\phi(w)$ —— 一個「二元開關」形式的分佈。**
>
> **每次 forward pass,就是從這個分佈採樣一次權重。**

---

## ③ 核心洞察 2:Dropout 的 loss 就是 ELBO

### Dropout 的標準訓練目標

$$\mathcal{L}_{\text{dropout}} = \underbrace{\frac{1}{N}\sum_i\text{loss}(y_i,\hat y_i)}_{\text{一般的訓練誤差}} + \underbrace{\lambda\|W\|^2}_{\text{L2 正則}}$$

**這就是你每天在寫的訓練 loss** —— 交叉熵/MSE + weight decay。

### VI 的訓練目標

$$-\text{ELBO} = -\mathbb{E}_{q_\phi}[\log p(D\mid w)] + \text{KL}\big(q_\phi(w)\,\|\,p(w)\big)$$

### 🪄 Gal 的證明:兩者等價

| Dropout loss | ELBO |
|---|---|
| **訓練誤差** $\frac1N\sum\text{loss}$ | **重建項** $-\mathbb{E}_q[\log p(D\mid w)]$ |
| **L2 正則** $\lambda\|W\|^2$ | **KL 項** $\text{KL}(q_\phi\|p(w))$ |

> 🔑 **震撼的結論**:
>
> **你每天在做的 Dropout + weight decay 訓練,數學上就是在最大化 ELBO。**
>
> **你一直在做變分推論,只是你不知道。**

### 為什麼 L2 對應 KL?

如果先驗是 $p(w) = \mathcal{N}(0,\sigma_0^2 I)$:

$$\text{KL}(q_\phi\|p(w))\approx\frac{1}{2\sigma_0^2}\|W\|^2 + \text{常數}$$

**這就是 L2 正則化(weight decay)。**

> 🔑 你在 [[1-1_四個項的認識論意義]] 學過:**L2 正則 = 高斯先驗 + MAP**。
> 現在升級版:**L2 正則 + Dropout = 高斯先驗 + VI**。

---

## ④ MC Dropout:測試時的魔法

既然 Dropout 訓練 = VI,那訓練好的 $W$ 就定義了一個近似後驗。

要得到貝葉斯預測,回到 [[3-2_後驗預測分佈]]:

$$p(y^*\mid x^*,D) = \int p(y^*\mid x^*,w)\,q_\phi(w)\,dw \approx \frac1T\sum_{t=1}^T p(y^*\mid x^*, w^{(t)})$$

### 🪄 從 $q_\phi$ 採樣 = 開著 Dropout 做 forward!

> **「從 $q_\phi(w)$ 採樣一個權重」= 「隨機決定哪些神經元被關掉」= 「跑一次帶 Dropout 的 forward pass」**

### 做法

```python
model.train()      # ← 關鍵:測試時保持 Dropout 開啟
preds = torch.stack([model(x) for _ in range(50)])

prediction  = preds.mean(0)
uncertainty = preds.std(0)
```

**就這樣。不用改架構、不用改訓練、不用重新訓練任何東西。**

**唯一的改變**:測試時**不要關掉 Dropout**,而且跑 $T$ 次。

```
標準測試(關 Dropout):
   x* → [全開網路] → ŷ = 0.87        ← 一個數字,沒有不確定性資訊

MC Dropout(開 Dropout,跑 50 次):
   x* → [隨機子網路 1] → 0.85
   x* → [隨機子網路 2] → 0.91
   x* → [隨機子網路 3] → 0.83
   ...
   → 平均 = 0.87,標準差 = 0.03    ← 有不確定性了!
```

---

## ⑤ 不確定性從哪裡「長」出來?

### 用「機制 → 對比 → 本質」三層來理解

#### 機制

MC Dropout 每次 forward 隨機關掉不同的神經元,所以每次得到的是**一個不同的子網路**。跑 50 次,就得到 50 個子網路的答案。

#### 對比

| 情境 | 發生什麼 | 結果 |
|---|---|---|
| **訓練充足的區域** | 網路學到**穩健**的表示,**很多神經元都在做類似的事**(冗餘高)→ 隨機關掉一些,**剩下的還是能算對** | 50 次答案很接近 → **標準差小** |
| **沒見過的區域** | 網路沒學到穩健表示,輸出**高度依賴特定幾個神經元**(冗餘低)→ 關掉不同神經元,**答案劇烈變化** | 50 次答案分歧大 → **標準差大** |

#### 本質

> 🔑 **不確定性 = 子網路之間的分歧程度。**
>
> **分歧小 = 這個答案很穩健,很多模型都同意**
> **分歧大 = 這個答案很脆弱,不同模型看法不同**

**這正是 [[6-1_貝葉斯神經網路]] 的「後驗 = 知道哪些模型和數據相容」的具體體現。**

## ⑥ 電機工程類比:冗餘系統的可靠度測試

你設計一個 N 重冗餘的關鍵系統(例如飛控)。**可靠度測試怎麼做?**

> **隨機模擬「某些單元故障」的情境,看系統輸出還對不對。**
>
> - **大部分故障組合下輸出都正確** → 系統穩健 ✅
> - **某些故障組合下輸出劇變** → 系統脆弱,有單點依賴 🚨

| 冗餘系統測試 | MC Dropout |
|---|---|
| 隨機讓某些單元故障 | 隨機關掉某些神經元 |
| 跑多次故障情境 | 跑 T 次 forward |
| 輸出一致 = 系統穩健 | 輸出一致 = 不確定性低 |
| 輸出劇變 = 有單點依賴 | 輸出劇變 = 不確定性高 |

> 🔑 **MC Dropout 本質上是在做「神經網路的冗餘度測試」** —— 測試這個預測**依不依賴特定的神經元**。

## ⑦ 代價與限制(誠實的部分)

### 🚨 限制 1:近似品質有爭議

**Dropout 定義的 $q_\phi(w)$ 是一個非常粗糙的家族** —— 每個權重只能是「原值」或「0」兩個狀態。真實後驗當然不長這樣。

**所以 MC Dropout 的不確定性估計常被批評「校準不佳」** —— 它給的 95% 區間可能實際只覆蓋 70%。

> ⚠️ 近年有不少論文指出 **MC Dropout 的 OOD 偵測效能常常被高估**。
> **如果你的實驗做出「效果沒有想像中好」的結論,那是好事** —— 誠實報告負面結果比硬做出漂亮數字更有專業價值。

### 🚨 限制 2:dropout rate 是固定的超參數

不確定性程度**強烈依賴 dropout rate $p$**:
- $p$ 太小 → 不確定性被低估
- $p$ 太大 → 不確定性被高估

而 $p$ 通常是**為了正則化效果調的**,不是為了不確定性估計調的 → **兩個目標可能衝突**。
(後續研究有 **Concrete Dropout**,讓 $p$ 可以被學習)

### 🚨 限制 3:預測成本 × T 倍

要跑 50 次 forward,**推論成本是 50 倍**。對即時系統(30fps)可能不可接受。
**工程折衷**:降低 $T$(例如 10 次),或只在關鍵決策時啟用。

### vs Deep Ensemble

| 面向 | MC Dropout | Deep Ensemble |
|---|---|---|
| **訓練成本** | ✅ 1 倍(**免費!**) | ❌ 5–10 倍 |
| **預測成本** | ❌ T 倍 | ❌ 5–10 倍 |
| **記憶體** | ✅ **1 個模型** | ❌ 5–10 個模型 |
| **不確定性品質** | ⚠️ 中等 | ✅ 通常更好 |
| **理論基礎** | ✅ VI(明確) | ⚠️ 較弱(但實證好) |

> 🔑 **記憶錨**
> **MC Dropout = 用「時間」換不確定性**(跑多次)
> **Deep Ensemble = 用「空間 + 訓練成本」換不確定性**(存多個模型)
>
> **看你缺哪個資源,就選另一個。**

### 實務判斷表

| 限制 | 該選什麼 |
|---|---|
| **記憶體緊 / 已有訓練好的模型** | ✅ **MC Dropout** |
| **訓練成本無所謂,要最好品質** | ✅ **Deep Ensemble** |
| **推論必須極快(單次 forward)** | ⚠️ 兩者都不行 → 用 SWAG 或 Deterministic Uncertainty Methods |
| **要嚴謹的理論保證** | ✅ MC Dropout(有 VI 基礎) |

### ⚠️ 一個實作陷阱

MC Dropout 測試時要 `model.train()` 而不是 `model.eval()`(否則 Dropout 被關掉)。

**但這樣 BatchNorm 也會進入訓練模式** → **建議 BNN 實驗不要用 BatchNorm,改用 LayerNorm 或 GroupNorm。**

## 🔗 回頭連結

| 你已學過的 | 在 MC Dropout 的位置 |
|---|---|
| **VI / ELBO** | Dropout 訓練 = 最大化 ELBO |
| **Mean Field** | Dropout 的 $q_\phi$ 也是各權重獨立 |
| **後驗預測分佈** | MC Dropout 用蒙地卡羅近似它 |
| **L2 正則 = 高斯先驗** | Dropout loss 的 L2 項 = ELBO 的 KL 項 |
| **貝葉斯模型平均** | T 次採樣平均 = BMA 的實現 |
| **Ensemble** | MC Dropout 是「單模型版的 ensemble」 |

## 🎓 費曼檢驗

### 問題 1
Gal 證明了「Dropout 訓練 = 變分推論」。說明這個對應的兩個關鍵環節。

> [!success]- 參考答案
> **環節 1 · Dropout 定義了什麼?**
> Dropout 讓權重變成一個**「二元開關」的隨機分佈**:$w_i = W_i$(機率 $p$)或 $0$(機率 $1-p$)。
> **每次 forward pass 就是從這個分佈採樣一次權重。**
> 所以 Dropout 不是「隨機關神經元的技巧」,而是**一個非常特殊的近似後驗 $q_\phi(w)$**(只是形狀很粗糙)。
>
> **環節 2 · loss 對應 ELBO 的哪兩項?**
> | Dropout loss | ELBO |
> |---|---|
> | 訓練誤差(交叉熵/MSE) | **重建項** |
> | L2 正則(weight decay) | **KL 項** |
>
> **所以你每天寫的訓練 loss,數學上就是 $-$ELBO。**

### 問題 2
為什麼訓練充足的區域標準差小、沒見過的區域標準差大?

> [!success]- 參考答案
> **機制**:MC Dropout 每次隨機關掉不同神經元,每次得到**一個不同的子網路**。跑 50 次得到 50 個答案。
>
> **對比**:
> - **訓練充足**:網路學到穩健的表示,**很多神經元在做類似的事(冗餘高)** → 關掉一些,剩下的還能算對 → **50 次答案接近 → 標準差小**
> - **沒見過**:輸出**高度依賴特定幾個神經元(冗餘低)** → 關掉不同神經元,答案劇烈變化 → **標準差大**
>
> **本質**:**不確定性 = 子網路之間的分歧程度。**
>
> 💡 **EE 類比**:就像測試 N 重備援飛控系統 —— 隨機讓某些單元故障,看輸出還對不對。**MC Dropout 做的就是神經網路的冗餘度測試。**

### 問題 3
三個系統選 MC Dropout 還是 Deep Ensemble?
- A:自駕車即時物體偵測(30fps,GPU 緊張,已有訓練好的模型)
- B:醫療影像診斷(離線批次,校準品質至上,預算充足)
- C:手機語音助理(記憶體極度受限,可接受多跑幾次)

> [!success]- 參考答案
> - **A → MC Dropout**。兩個關鍵線索:**GPU 緊張**(Ensemble 要載入 5–10 個模型 → 記憶體爆炸)、**已有訓練好的模型**(Ensemble 要重訓 5–10 次)。MC Dropout 不用重訓、只要一個模型記憶體,還能調低 $T$ 配合 30fps。
>   *(補充:真實自駕車實務上還會考慮「只在關鍵時刻啟用」或改用 SWAG 等單次 forward 的方法)*
> - **B → Deep Ensemble**。有預算、有時間、要最好的校準品質。
> - **C → MC Dropout**。**記憶體受限是關鍵** —— Ensemble 要存 5–10 個模型,手機裝不下。用時間換空間。
