# 5-3 · 重參數化技巧

> [!abstract] 這是現代生成模型的命脈
> **VAE 為什麼能訓練?Diffusion 為什麼能訓練?—— 有一半建立在這個技巧上。**
>
> 它解決一個看似簡單、但極度致命的問題:**「我要算對隨機變數的梯度,但梯度不能穿過『採樣』這個動作。」**

> [!question] 本卡核心問題
> - 為什麼「採樣」會擋住梯度?
> - 重參數化用什麼小招解決?
> - 為什麼這是 VAE、Diffusion 能訓練的真正關鍵?

---

## ① 問題:採樣切斷了梯度

反向傳播能算梯度的條件是:**整條計算路徑必須是「可微的函數鏈」**。

VI 訓練時有一個動作**徹底打破這個鏈** —— 「從分佈中採樣」。

```
參數 φ → 分佈 q_φ(θ) → 採樣 θ ~ q_φ → 計算 log p(D|θ)
   ↑                       ↑
  需要梯度!            「採樣」不可微,梯度到這裡就斷了
```

### 為什麼隨機數會擋住梯度?

> 🔑 **梯度需要的是「確定性的函數關係」** —— 「$y = f(x)$,改 $x$ 一點點,$y$ 會變多少」。
>
> **採樣是「隨機性的選擇」** —— 同樣的 $\phi$,每次採出來的 $\theta$ 都不同。
>
> **梯度問:「改 φ 一點點,θ 會變多少?」** —— 但答案是「不一定」(每次不同),**所以梯度不存在**。

**採樣本質上不是函數,是隨機過程 —— 這是反向傳播的死敵。**

---

## ② 🪄 核心招數

### 原本

$$\theta \sim \mathcal{N}(\mu_\phi, \sigma_\phi^2)$$

### 重參數化後

$$\boxed{\;\theta = \mu_\phi + \sigma_\phi\cdot\epsilon,\qquad \epsilon\sim\mathcal{N}(0,1)\;}$$

> 🔊 **念**:「θ 等於 $\mu_\phi$ 加上 $\sigma_\phi$ 乘以 ε,其中 ε 從標準常態採樣」

### 兩種寫法數學上等價嗎?

**是的** —— 這是高斯分佈的線性變換性質。結果分佈完全相同。

### 🎯 但梯度可及性完全不同

**重參數化前**:
```
φ →[採樣 q_φ]→ θ → f(θ)
        ↑
   隨機操作,截斷梯度
```

**重參數化後**:
```
φ ───┐
     ├→ θ = μ_φ + σ_φ × ε → f(θ)
ε ───┘   (確定性函數)
(從固定分佈來,跟 φ 無關)
```

**現在從 φ 到 θ 是一條可微的計算路徑** —— 只是中間插入了一個隨機常數 ε。

$$\frac{\partial\theta}{\partial\mu_\phi} = 1,\qquad \frac{\partial\theta}{\partial\sigma_\phi} = \epsilon$$

**梯度可以順利從 $f(\theta)$ 流回 $\phi$!**

### 🔑 一句話

> **重參數化把隨機性從「跟 φ 有關的分佈」搬到「跟 φ 無關的固定分佈」,讓 φ 到 θ 的關係變成「確定性函數 + 一個隨機常數」。**
>
> **這樣梯度可以流過 φ 到 θ 的關係,把隨機性「繞過去」。**

---

## ③ 替代方案:Score Function Estimator

不用重參數化,還是有辦法估計梯度:

$$\nabla_\phi\mathbb{E}_{q_\phi}[f(\theta)] = \mathbb{E}_{q_\phi}\big[f(\theta)\,\nabla_\phi\log q_\phi(\theta)\big]$$

這叫 **score function estimator**,RL 裡的 **REINFORCE** 用的就是這個。

### 對比

| 面向 | 重參數化 | Score Function |
|---|---|---|
| **需要可微的 $f$?** | ✅ 需要 | ❌ 不需要 |
| **需要可重參數化的分佈?** | ✅ 需要(高斯、Laplace 可以) | ❌ 任何分佈都可 |
| **估計變異數** | **小**(訓練穩定) | **大**(訓練不穩) |
| **適用場景** | VAE、Diffusion、BNN | RL 的離散動作、不可微 reward |

### 為什麼變異數差這麼多?

- **重參數化**用「具體的 ε」算梯度 —— 每次採樣的梯度都有**穩定的方向**
- **Score function**用「對數似然的梯度作權重」估計 —— 權重在不同採樣間劇烈變化,**梯度雜訊很大**

> 🔑 **VAE 為什麼能訓練得這麼好?因為高斯後驗能重參數化,梯度變異數小,訓練極穩。**
>
> **RL 為什麼這麼難訓?因為動作通常離散,只能用 score function,梯度雜訊大** —— 這就是 PPO、Actor-Critic 要做各種招數降低梯度變異數的原因。

## ④ 電機工程類比:確定 + 隨機的分解

### 加性高斯白雜訊模型

訊號處理裡你會看到:

$$y = h\theta + n,\qquad n\sim\mathcal{N}(0,\sigma^2)$$

**「確定的訊號 + 隨機的雜訊」的標準分解。**

### 重參數化的精神完全一樣

$$\theta = \underbrace{\mu_\phi}_{\text{確定}} + \underbrace{\sigma_\phi}_{\text{確定尺度}}\cdot\underbrace{\epsilon}_{\text{隨機}}$$

### 🔑 EE 工程師為什麼一輩子在做這個分解?

> **不是「方便除錯」,而是「讓兩套不同的數學工具各自發揮全力」。**

| 理由 | 說明 |
|---|---|
| **1. 分而治之** | **確定部分**用線性系統理論分析、設計、控制;**隨機部分**用統計工具(均值、方差、相關函數)分析 |
| **2. 可控 vs 不可控** | 確定部分**可以**設計調整;隨機部分**無法**控制,只能量化其統計性質 |
| **3. SNR 的概念** | 訊雜比可以明確定義 —— 整個通訊系統的設計都建立在這個分解上 |
| **4. 梯度可流** | 重參數化的版本:確定部分可微 → 梯度下降能對它發揮全力 |

| | 工程版(訊號) | 貝葉斯版(重參數化) |
|---|---|---|
| **確定部分** | $h\theta$(可控訊號) | $\mu_\phi + \sigma_\phi\cdot(\cdot)$(可微結構) |
| **隨機部分** | $n$(白雜訊) | $\epsilon$(標準常態) |
| **為什麼分開** | 可分析、可設計 | **可微、可訓練** |

## ⑤ 為什麼這是 VAE / Diffusion 的命脈?

### 🎨 VAE 的訓練

```
輸入 x → Encoder → μ_φ(x), σ_φ(x) → 採樣 z → Decoder → 重建 x̂
                                      ↑
                                 這裡是關鍵
```

- **沒有重參數化**:採樣 z 這一步擋住梯度,**整個 Encoder 沒法訓練**
- **有重參數化**:`z = μ_φ(x) + σ_φ(x) × ε`,梯度可以流回 Encoder

> 🔑 **VAE 之所以能訓練,完全靠重參數化。**

### 🌊 Diffusion Model 的訓練

$$x_t = \sqrt{1-\beta_t}\,x_{t-1} + \sqrt{\beta_t}\,\epsilon,\qquad \epsilon\sim\mathcal{N}(0,I)$$

**看!這就是重參數化的形式** —— 「確定部分 + 隨機部分 × 尺度」。

**Diffusion 的每一步 forward process 都是重參數化的應用** —— 這就是為什麼它能用反向傳播訓練。

### 🤖 貝葉斯神經網路

每個權重都有分佈 $q_\phi(w)$:$w = \mu_\phi + \sigma_\phi\cdot\epsilon$

**這就是貝葉斯深度學習能規模化的關鍵。** → [[6-1_貝葉斯神經網路]]

### 🔧 額外的好處:MCMC 裡也救命

PyMC 的階層模型常出現 **divergences**(funnel 問題)。解法是 **non-centered parameterization**:

```python
# 中心化(容易 diverge)
a = pm.Normal("a", mu_a, sigma_a, shape=n)

# 非中心化(建議)—— 這就是重參數化!
a_raw = pm.Normal("a_raw", 0, 1, shape=n)
a = pm.Deterministic("a", mu_a + sigma_a * a_raw)
```

> 🔑 **同一個技巧,在 VI 裡讓梯度能流,在 MCMC 裡讓採樣器不卡住。**

### 歷史意義

> **Kingma & Welling 2013 年的 VAE 論文,核心貢獻就是「把重參數化技巧引入深度生成模型訓練」。**
>
> **一個簡單到像是「換個寫法」的招數,引爆了一個時代。**
>
> **沒有它,現代深度生成模型的革命可能延遲十年甚至無法發生。**

## 🎓 費曼檢驗

### 問題 1
為什麼採樣會擋住梯度?

> [!success]- 參考答案
> 採樣把 φ 和 θ 之間的**可微關係切斷了**。
>
> 梯度需要「確定性的函數關係」—— 改 x 一點點,y 會變多少。但採樣是隨機的:同樣的 φ,每次採出來的 θ 都不同,所以「改 φ 一點點,θ 會變多少」的答案是「不一定」→ **梯度不存在**。
>
> **採樣本質上不是函數,是隨機過程。**

### 問題 2
重參數化把「隨機性」搬到哪裡了?搬完之後為什麼梯度能流?

> [!success]- 參考答案
> **隨機性被「外包」給 ε** —— 一個**跟 φ 完全無關**的固定分佈 $\mathcal{N}(0,1)$。
>
> 搬完之後,**φ 和 θ 之間變成純粹的確定性函數** $\theta = \mu_\phi + \sigma_\phi\epsilon$。ε 只是一個隨機常數,不影響可微性。
>
> 所以 $\frac{\partial\theta}{\partial\mu_\phi} = 1$、$\frac{\partial\theta}{\partial\sigma_\phi} = \epsilon$ 都可以直接算 —— **梯度無痛流過**。

### 問題 3
訊號處理的 $y = h\theta + n$ 和重參數化 $\theta = \mu_\phi + \sigma_\phi\epsilon$ 有什麼精神上的相同?

> [!success]- 參考答案
> **兩者都是「把確定部分和隨機部分分開」。**
>
> ⚠️ 但理由不只是「方便除錯」—— **真正的理由是「讓兩套不同的數學工具各自發揮全力」**:
>
> | 部分 | 用什麼工具 |
> |---|---|
> | 確定部分 | 線性系統理論、設計、控制、**梯度下降** |
> | 隨機部分 | 統計工具(均值、方差、相關函數) |
>
> **分開後,兩套工具各自能發揮全部力量。** 在訊號處理裡,這讓 SNR 的概念成立、讓整個通訊系統的設計可能;在貝葉斯裡,這讓梯度下降能對「結構部分」發揮全力。
