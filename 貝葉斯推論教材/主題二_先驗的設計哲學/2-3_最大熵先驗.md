# 2-3 · 最大熵先驗

> [!abstract] 這是主題二的統一定理
> 你會看到三個以為獨立的東西 —— **資訊理論的最大熵原理、共軛先驗、指數族分佈** —— 在這裡**完全合而為一**。

> [!question] 本卡核心問題
> 前兩張卡處理了兩個極端:
> - **Jeffreys**:我什麼都不知道 → 先驗長什麼樣?
> - **共軛**:我只關心計算方便 → 先驗長什麼樣?
>
> 但真實世界通常是中間狀態:**「我知道一些事情(平均值、變異數),但其他的我不想假設。」**
> 這時候該選什麼?

---

## ① 直覺鋪墊:誠實的統計學家

有人告訴你「某顆電阻的平均值是 $100\,\Omega$,標準差是 $1\,\Omega$」。你只有這兩個資訊。

滿足這兩個條件的分佈**有無限多個**:

- 高斯 $\mathcal{N}(100,1)$ ✅
- 均勻 $U(100-\sqrt3, 100+\sqrt3)$ ✅
- 雙峰 $0.5\mathcal{N}(99,0.5^2)+0.5\mathcal{N}(101,0.5^2)$ ✅
- 某個奇形怪狀的三峰分佈 ✅

**選哪個?**

- 選**雙峰** → 你暗示了「我相信電阻有兩個 typical 值」。但這個信念從哪來?**你偷偷加了一個不該有的假設。**
- 選**均勻** → 你暗示了「電阻不可能超過 $100\pm\sqrt3$」。這個硬截斷也是別人沒告訴你的。

> 🔑 **「誠實」= 只編碼你已知的兩個約束,除此之外什麼都不假設。**
>
> **「什麼都不假設」怎麼數學化?→ 選熵最大的那個分佈。** 因為熵最大 = 最不確定 = 沒有多餘的結構。

**猜猜誰是幸運兒?答:高斯分佈。**

這就是那句在教科書上讓人摸不著頭緒的名言:

> **「高斯分佈是在二階矩約束下最大熵的分佈。」**

現在你知道它在說什麼了。

---

## ② 正式定義與推導

### 問題設定

已知資訊是一組**期望約束**:

$$\mathbb{E}_p[T_k(\theta)] = \mu_k,\qquad k=1,\ldots,K$$

**最大熵原理**:

$$p^*(\theta) = \arg\max_p H(p)\quad\text{s.t. } \mathbb{E}_p[T_k(\theta)]=\mu_k,\;\int p = 1$$

### 用 Lagrange 乘數法求解

(這裡直接用上你**第一層優化核心**學的約束優化)

$$\mathcal{L}(p) = -\int p\log p\,d\theta - \sum_k\lambda_k\left(\int T_k p\,d\theta - \mu_k\right) - \lambda_0\left(\int p\,d\theta - 1\right)$$

對 $p$ 變分求極值:

$$\frac{\delta\mathcal{L}}{\delta p} = -\log p - 1 - \sum_k\lambda_k T_k - \lambda_0 = 0$$

解出:

$$\boxed{\;p^*(\theta) = \frac{1}{Z}\exp\left(\sum_k\lambda_k T_k(\theta)\right)\;}$$

### 🎯 這就是指數族的一般形式!

對照指數族:$p(\theta) = h(\theta)\exp(\eta^\top T(\theta) - A(\eta))$ —— **完全一樣**。

$\lambda_k$ 就是自然參數,$T_k$ 就是充分統計量,$Z$ 就是 $e^{A(\eta)}$。

> [!important] 🔑 中央定理(把這個記進腦子,永生受用)
> $$\textbf{最大熵分佈} = \textbf{指數族分佈} = \textbf{有共軛先驗的分佈}$$
> **三位一體。**

**這不是巧合**:Lagrange 求最大熵解時,指數函數是**必然產物**;而指數結構本身又決定了共軛性。

## ③ 反直覺例子:為什麼高斯這麼「無所不在」?

### 不同約束下的最大熵分佈

| 你知道的約束 | 最大熵分佈 |
|---|---|
| 僅支撐集(有界區間 $[a,b]$) | **均勻分佈** |
| 支撐集 $[0,\infty)$ + 均值 | **指數分佈** |
| 支撐集 $\mathbb{R}$ + 均值 + 變異數 | **高斯分佈** |
| 支撐集 $[0,\infty)$ + 均值 + $\mathbb{E}[\log\theta]$ | **Gamma 分佈** |
| 支撐集 $\{0,1\}$ + 一階矩 | **Bernoulli 分佈** |
| 支撐集 $\{0,1,2,\ldots\}$ + 均值 | **Poisson 分佈** |

### 高斯無所不在的第二個解釋

大部分人以為是**中央極限定理**(很多東西的總和趨向高斯)。

**最大熵給了一個不同、更深的回答**:

> 🔑 **高斯不是因為 CLT 才無所不在,是因為我們大多數時候只測量了前兩階矩。**

你做訊號處理時怎麼描述雜訊?「平均是 0,功率是 $\sigma^2$」—— **這就是一階矩和二階矩**。你沒提更高階的矩。

**在「只有二階矩資訊」的前提下,最誠實的選擇就是高斯** —— 不是因為雜訊「天生」是高斯,而是因為**我們對它的了解到此為止**。

> [!warning] 🚨 這裡的因果方向極容易搞反
> **錯誤的說法**:「因為資料呈現高斯分佈,所以我們選高斯。」← 這是**循環論證**
>
> **正確的順序**:
> 1. 我知道的**只有**某些約束(例如均值、變異數)
> 2. **在這些約束下**,拉格朗日優化選熵最大的分佈
> 3. 這個分佈**剛好**是高斯 —— **數學逼出來的,不是我選的**
>
> **最大熵是從「無知」推出「形狀」,不是從「形狀」推出「形狀」。**

### 兩個解釋是互補的

| | CLT 的解釋 | 最大熵的解釋 |
|---|---|---|
| **回答什麼?** | 高斯為什麼在**自然界**頻繁出現 | 高斯為什麼在**工程建模**中頻繁出現 |
| **性質** | 客觀的生成機制 | 主觀的認知限制 |

**兩者一起解釋了為什麼高斯到處都是。**

### 這對 KF 的意義

**KF 用高斯不是因為量測噪音「真的」是高斯,而是因為工程上我們只能量到方差。**

反過來說:**當你能測到更高階矩**(例如 IMU 鋸齒讓你觀察到「超額峰度」),**高斯就不再是誠實的選擇** —— 你應該換成 Student-t 或 Laplace。

> 🔑 **這就是 robust filter 的資訊理論依據。**
>
> 當數據的行為本身告訴你「存在重尾」,你還硬套高斯,就是**「假裝不知道自己已經知道的事」** —— 這已經不是保守,是刻意遮眼。

## ④ 電機工程類比:熱平衡與 Boltzmann 分佈

統計力學的核心問題:給定系統的平均能量 $\bar E$(唯一的宏觀約束),系統處於狀態 $s$ 的機率是多少?

$$p(s) = \frac{e^{-\beta E_s}}{Z},\qquad Z = \sum_s e^{-\beta E_s}$$

**這就是在「平均能量 = $\bar E$」這個單一約束下的最大熵分佈:**

- 充分統計量 $T(s) = E_s$
- Lagrange 乘數 $\lambda = -\beta$(物理上叫 inverse temperature)
- 歸一化 $Z$ = partition function

> 🔑 **Boltzmann 分佈 = 最大熵 = 指數族,三者完全同一。**

### 深層直覺

- **自然界的熱平衡,其實是宇宙的「最保守猜測」** —— 系統知道的只有平均能量,所以微觀狀態的分佈就是在這個約束下最混亂的分佈
- **貝葉斯的最大熵先驗,是統計學家在仿效自然界的做法**
- **partition function $Z$ = marginal likelihood $p(D)$** —— 同一個數學物件在不同領域的名字

你在 EE 遇到的其他版本:雷射的反轉粒子數分佈、電子在導帶的分佈、黑體輻射 —— 都是最大熵分佈的物理實例。

## ⑤ 主題二的大團圓

| 卡片 | 問題 | 哲學立場 |
|---|---|---|
| **[[2-1_無資訊先驗與Jeffreys]]** | 我什麼都不知道,先驗是什麼? | **不變性**:無知不該因參數化選擇而改變 |
| **[[2-2_共軛先驗與指數族]]** | 我想計算漂亮,先驗是什麼? | **實用性**:先驗選在家族封閉的地方 |
| **2-3 最大熵** | 我知道某些約束,其餘不想假設 | **誠實性**:只編碼已知,熵最大化 |

### 三條哲學路線殊途同歸

- 共軛先驗的形式 → **指數族**
- 最大熵先驗的形式 → **指數族**
- Jeffreys Prior 常常也落在指數族(Bernoulli 的 Jeffreys 是 Beta)

> 🔑 **指數族不是眾多分佈家族中「湊巧」有好性質的那一個。**
>
> **它是機率論的「語法規則」** —— 任何合理的統計推論路徑都會被它的結構吸引。
>
> 這就是為什麼我們花這麼多力氣學它 —— **它不是一個工具,它是統計學的自然座標系**。

### 最終極的縫合

> **最大熵先驗(貝葉斯) = MLE(頻率學派) = KL 最小化(資訊理論) = 指數族的共軛結構(統計)。**
>
> 整個統計機器學習的數學基石,歸宿都在同一個指數族家族。

推理鏈:
- MLE 在 i.i.d. + 經驗分佈下等價於最小化交叉熵
- 交叉熵最小化等價於 KL 散度最小化
- KL 散度 + 最大熵統一成 I-projection(資訊投影)

## 🎓 費曼檢驗

### 問題 1
從最大熵的角度,給出「高斯為什麼無所不在」的另一個解釋。它和 CLT 矛盾嗎?

> [!success]- 參考答案
> **最大熵的解釋**:高斯在工程建模中無所不在,是因為人類在測量時通常只能量到前兩階矩(均值、變異數),更高階矩非常難準確估計。**在只知道前兩階矩的前提下,拉格朗日優化必然給出高斯** —— 這是數學逼出來的,不是我們選的。
>
> **兩者互補,不矛盾**:CLT 說「自然界讓它出現」(客觀生成機制);最大熵說「我們的無知讓我們選它」(主觀認知限制)。
>
> ⚠️ 注意因果方向:**不是「看到高斯所以選高斯」**(那是循環論證),而是「**約束 → 優化 → 形狀**」。

### 問題 2
三種不同哲學(Jeffreys / 共軛 / 最大熵)在 Bernoulli 情境下都落在 Beta 家族。這告訴你什麼?

> [!success]- 參考答案
> - **Jeffreys 走「幾何」路線**(分佈空間的不變性)→ $\text{Beta}(1/2,1/2)$
> - **共軛走「代數」路線**(家族封閉)→ Beta 家族
> - **最大熵走「資訊論」路線**(約束下熵最大)→ Beta 家族
>
> **深層意思**:當你選一個似然模型(例如 Bernoulli),它**就已經決定了** —— 透過它作為指數族的結構 —— 與它相配的先驗該長什麼樣。無論走哪條路,你都會撞到同一個家族。
>
> **指數族是統計學的自然座標系,不是眾多家族中湊巧好用的那一個。**

### 問題 3
「為什麼幾乎總是假設量測噪音是高斯?這是物理事實還是建模選擇?」

> [!success]- 參考答案
> **是建模選擇,而且在特定條件下是誠實的選擇。**
>
> 我們一般只測量了前兩階矩,沒有更高階矩的資訊。在這個前提下,高斯是最大熵分佈 —— **最保守、不包含任何額外假設**。
>
> **但如果我們已經知道更高階矩**(例如 IMU 鋸齒告訴你峰度極高),還硬用高斯就是**偷懶甚至有害** —— 因為那已經不符合最大熵原理,你在「假裝不知道自己已經知道的事」。
>
> **正確的升級是換成 Student-t 或 Laplace** —— 它們是「均值 + 變異數 + 部分峰度資訊」的最大熵分佈。這就是 robust filter 的資訊論依據。
